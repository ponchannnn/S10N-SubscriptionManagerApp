# サブマネ・石井担当の実装

提供されたREADME2.mdの担当表に基づき，Python＋Fletで登録画面と解約・再契約，グレーアウト，並び替えを実装しています．APIサーバは未完成のため，main.pyとviews/preview.pyは担当機能を単独確認するための仮の起動・確認画面です．他の担当者のホーム・詳細・ログイン・内訳・期限画面を実装したものではありません．

## 起動

このフォルダに準備した.venvを使う場合：

```powershell
cd 'C:\Users\Yuto\ICTⅡ\S10N-SubscriptionManagerApp\submane'
.\.venv\Scripts\python.exe .\src\main.py
```

ブラウザで確認する場合：

```powershell
.\.venv\Scripts\python.exe .\src\main.py --web
```

ポート8550を使用中なら `--port 8551` を付けます．GUIを自動で開かずサーバだけ起動する場合は `--headless` を付けます．

別のPCではPython 3.12を用意し，次のコマンドで専用環境を作ります．

```powershell
.\setup.ps1
.\run.ps1
```

Fletは1.0.3に固定しています．手元のPCにはPython 3.14.4のみがあったため，初回の実行検証は3.14.4を使用しています．Python 3.12およびAndroid実機の確認は別途必要です．玉造ブランチの共通コードもFlet 1.0.3を使用しています．

## 作った機能

- サービス名称検索．全角英数字と大文字・小文字の違いを吸収します．
- 定番サービスを選び，プラン名・金額・周期・入退会URL・退会メモを自動入力します．プラン名・金額・周期は入力後に修正できます．定番の名称・URL・退会案内はマスタの値を使い，変更する場合は手入力へ切り替えます．
- 定番にないサービスを手入力できます．URLは任意で，未登録でも保存できます．
- 入会日時を分単位で入力します．月額・年額，契約中・トライアル中を選択できます．解約済みへの切り替えは登録後の詳細画面で行います．
- トライアル中は終了日時を入力します．登録した金額は有料移行後の1回の支払額です．
- 必須項目，整数の金額，実在する日時，URLを検証します．入力エラーは各欄に表示します．
- 登録ボタンの二重送信を防ぎ，保存中は入力を止めます．保存失敗時には内容を残します．
- 公式サイトを開くボタンと，手続き完了後の契約状態を記録するボタンを提供します．
- 解約済みはデータとアイコンを残し，グレーアウトして一覧末尾へ移します．
- 再契約では同じIDとURLを保ち，入会日時を更新し，古い次回支払日時を消します．
- 無料トライアルのアイコンに時計を表示します．画像URLがない場合は頭文字を使います．
- 更新頻度順・登録順と，次回支払日時を受け取った場合の期限順に対応します．
- JSONへ保存し，アプリ再起動後も登録内容を読み出します．通信・保存エラーには再試行案内を表示します．

## 試す手順

1. 「サブスクを追加」→「定番サービスを表示・検索」→動画サービス（デモ）を選び，プランを切り替えて自動入力を確認します．
2. 内容を登録し，一覧の件数が変わることを確認します．
3. 別のサービスを無料トライアル中として登録し，終了日時と時計の表示を確認します．
4. 一覧で契約を開き，公式サイトでの手続き完了にチェックして「解約済みとして記録」を押します．グレーアウトと末尾への移動を確認します．デモURLは実際の契約・解約を行いません．
5. 解約済みの契約を開き，再契約の入会日時を入力して「再契約済みとして記録」を押します．
6. 更新頻度順と登録順を切り替えます．期限順ではトライアル終了日時のある契約が並び替わります．
7. アプリを終了して再起動し，保存内容が残ることを確認します．

## 保存先とマスタ

保存先はPCでは既定で `C:\Users\Yuto\ICTⅡ\S10N-SubscriptionManagerApp\submane\data\subscriptions.json` です．FletからFLET_APP_STORAGE_DATAが提供される環境ではその保存領域を使います．チーム統合前のローカル保存であり，アカウントごとの分離や複数端末の同期は実APIが担当します．パスワードの入力欄はありません．

作業フォルダ内へ保存したい場合は起動前に環境変数を指定できます．

```powershell
$env:SUBMANE_DATA_FILE = 'C:\Users\Yuto\ICTⅡ\S10N-SubscriptionManagerApp\submane\data\subscriptions.json'
.\.venv\Scripts\python.exe .\src\main.py
```

dummy_data.pyのサービス名・料金・URLは架空のデモ情報です．正式マスタを担当者から受け取って差し替える前提です．実サービスの解約先や料金を推測して掲載していません．

## 決定・仮定と残る確認

- ユーザ確認済み：Python＋Flet．共通コードは玉造ブランチに存在し，APIサーバはまだ未完成です．
- ユーザ確認済み：更新頻度順と登録順を実装し，期限順はAPIから次回支払日時を受け取る追加機能とします．
- 更新READMEで確定：状態変更は公式サイトで利用者が手続きした後に手動で記録します．
- トライアル終了日時はユーザ入力とし，通常契約への自動移行は行いません．
- 更新READMEで確定：認証はCookie／Session，トライアルの次回支払日は終了日時，アイコンはAPI受け取りです．年額の計上方式選択と利用継続判断の見送りは他担当の範囲です．
- ユーザ確認済み：石井担当には日付計算を追加せず，担当者の計算結果を受け取ります．再契約時に古い日付を消し，新しい計算結果を受け取ります．現在はリポジトリ内のサーバ設計書v0.2に接続部分を合わせています．実APIサーバはまだ未完成です．
